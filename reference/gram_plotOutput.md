# Shiny output binding for a gram plot

Shiny output binding for a gram plot

## Usage

``` r
gram_plotOutput(outputId, width = "100%", height = "400px")
```

## Arguments

- outputId:

  Output variable to read from.

- width, height:

  Valid CSS dimensions.

## Value

A Shiny widget output element.
