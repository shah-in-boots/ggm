# Compile a tracing to SVG and a timeline spec

Compile a tracing to SVG and a timeline spec

## Usage

``` r
tracing_spec(x)
```

## Arguments

- x:

  A `Tracing`.

## Value

A list with `version`, `width`, `height`, `svg`, and `ops`.
