# Draw the traces on, like pen on paper

Draw the traces on, like pen on paper

## Usage

``` r
reveal(x, duration = 1200, stagger = 180)
```

## Arguments

- x:

  A `Tracing`.

- duration:

  Milliseconds for one channel to finish drawing.

- stagger:

  Milliseconds each channel waits behind the one above it.

## Value

The tracing, with the operation appended.
