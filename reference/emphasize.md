# Mark a point for emphasis

Mark a point for emphasis

## Usage

``` r
emphasize(x, target, label = NULL, duration = 450)
```

## Arguments

- x:

  A `Tracing`.

- target:

  A point from
  [`at()`](https://shah-in-boots.github.io/gram/reference/at.md).

- label:

  Optional text drawn beside the mark.

- duration:

  Milliseconds for the mark to appear.

## Value

The tracing, with the operation appended.
