# Visible window implied by a sweep speed

Visible window implied by a sweep speed

## Usage

``` r
sweep_window_seconds(sweep_speed_mm_s, screen_width_mm = 500)
```

## Arguments

- sweep_speed_mm_s:

  Sweep speed in millimetres per second.

- screen_width_mm:

  Physical plot width in millimetres.

## Value

Visible window in seconds.
