# Shiny output binding for a tracing

Shiny output binding for a tracing

## Usage

``` r
gram_tracingOutput(outputId, width = "100%", height = "400px")
```

## Arguments

- outputId:

  Output variable to read from.

- width, height:

  Valid CSS dimensions.

## Value

A Shiny widget output element.
