# Refer to a point on a channel

`at()` names a sample on a channel so a verb can resolve it to a
position.

## Usage

``` r
at(sample, channel)
```

## Arguments

- sample:

  Sample index.

- channel:

  Channel label.

## Value

A `gram_at` reference.
